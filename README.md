# Website To Do List

## GoodToDo

GoodToDo adalah sebuah website yang digunakan untuk mencatat kegiatan sehari-hari.

## Teknologi yang digunakan

Berikut teknologi yang saya gunakan untuk membuat website ini:

- Laravel
- Tailwind CSS

## Instalasi

1. Clone repository ini.
2. Simpan ke folder htdocs jika menggunakan XAMPP.
3. Buka kode editor favorit Anda, lalu pilih folder yang sudah di-clone.
4. Buka terminal kemudian ketikkan `php artisan migrate` lalu ketikkan `npm run dev`.
5. Buka terminal baru kemudian ketikkan `php artisan serve` lalu ketikkan `http://127.0.0.1:8000` pada browser.

## Fitur

1. Admin
- Melihat data user.
- Membuat, mengubah dan menghapus to do list.
- Mengubah status to do list.

2. User
- Membuat, mengubah dan menghapus to do list.
- Mengubah status to do list.
